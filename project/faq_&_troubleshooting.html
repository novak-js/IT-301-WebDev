Before building

How do I know if my parts will work together?

Check the motherboard's CPU support list and required BIOS version, supported memory, and case dimensions. Confirm that the power supply suits your parts. The component guide explains these checks.

Do I need a separate graphics card?

A processor with integrated graphics can handle many everyday tasks without a separate card. Check the processor's specifications and your software's requirements. Motherboard display ports alone do not guarantee integrated graphics support.

Do the sample build budgets include a monitor?

No. The sample builds cover the PC tower only. Budget separately for a monitor, keyboard, mouse, and any operating system license you need. The amounts are example targets, not live shopping totals.

During assembly

Which slots should I use for RAM?

Follow the recommended memory configuration in your motherboard manual. Slot choices depend on the board and the number of modules, so do not assume that any two slots are equivalent.

Do I need to add thermal paste?

Check whether the cooler already has paste applied. If it does, additional paste is usually unnecessary. Otherwise, apply paste as directed by the cooler manufacturer before fitting the cooler.

Can I reuse cables from another modular power supply?

Only use cables approved for your exact PSU model. Modular cables are not universally interchangeable, even when the plugs appear to fit. Check with the manufacturer if you are unsure.

Troubleshooting

Before reseating parts or changing internal connections, shut down the PC, switch off the PSU, and unplug it.

Nothing happens when I press the power button. What should I check?
  1. Check the wall outlet, power cable, and PSU switch.
  2. With power disconnected, check the motherboard and CPU power connections.
  3. Use the motherboard manual to check the case power-button connector.
The fans spin, but there is no picture. What now?

Check monitor power, the selected input, and the display cable. Connect to the graphics card if one is installed. Motherboard video output requires supported integrated graphics. Consult the manual for any diagnostic lights or beep codes.

Why is some of my RAM missing?

Check the detected capacity in BIOS/UEFI. With power disconnected, reseat the modules and verify their slots. Try one module at a time in the manual's recommended slot, and confirm the memory is supported.

My PC reaches BIOS, but the operating system does not start. Why?

A new drive may need an operating system installed. If one is already installed, check that the drive is detected and the correct boot entry is selected. For SATA drives, check data and power connections with the PC unplugged.

What should I check if the CPU gets too hot?

Compare temperatures with the CPU manufacturer's limits. Check fan operation and airflow. If temperatures rise rapidly toward the limit, shut down. With power disconnected, review cooler mounting, protective-film removal, and thermal paste using the cooler's instructions.

Still need a hand?

Revisit the building guide or consult the manual for your exact component.

For more detailed startup checks, see ASUS startup troubleshooting and AMD boot troubleshooting. Contact the component manufacturer if the problem continues.
